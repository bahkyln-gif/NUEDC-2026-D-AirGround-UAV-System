# 03 · 无线通信协议

> 同一 WiFi 局域网，UDP 通信，JSON 编码（UTF-8）。默认地面站端口 **14551**，无人机伴机端口 **14552**，小车（ESP32）端口 **14553**。广播地址 `255.255.255.255` 或组播 `239.255.0.1:14550`。

## 1. 通用帧格式

```json
{
  "type": "消息类型",
  "ts": 1234567890.123,
  "from": "car|uav|gs",
  "data": { ... }
}
```

## 2. 消息定义

### 2.1 `UAV_START`（小车 → 无人机）

```json
{
  "type": "UAV_START",
  "ts": 1722230000.0,
  "from": "car",
  "data": { "mode": "DELIVERY" }
}
```

- `mode`：`DELIVERY`（抛投任务）/ `DYNAMIC_LAND`（动态起降任务）。由小车按键选择（长按 2s 切换，短按启动）。

### 2.2 `CAR_TELEMETRY`（小车 → 地面站 / 转发给无人机）

```json
{
  "type": "CAR_TELEMETRY",
  "ts": 1722230000.1,
  "from": "car",
  "data": {
    "x": 125.0, "y": 95.0,
    "s": 267.8,
    "v": 12.0,
    "psi": 90.0,
    "state": "RUNNING"
  }
}
```

- `(x,y)`：场地坐标 cm（原点左下角）；`s`：累计里程 cm；`psi`：航向角 deg；`state`：`IDLE/RUNNING/DONE/STOP`。

### 2.3 `UAV_TELEMETRY`（无人机 → 地面站）

```json
{
  "type": "UAV_TELEMETRY",
  "ts": 1722230000.2,
  "from": "uav",
  "data": {
    "x": 130.0, "y": 100.0,
    "alt": 149.5,
    "vx": 0.5, "vy": 0.2,
    "psi": 90.0,
    "state": "FORMATION",
    "batt": 11.6
  }
}
```

- `state` 取值见系统架构状态枚举：`IDLE/TAKEOFF/HOVER/FORMATION/DELIVERY/RETURN/LAND/DYNAMIC_LAND/RECHOVER/DONE/FAIL`。

### 2.4 `GS_CMD`（地面站 → 任意端）

```json
{
  "type": "GS_CMD",
  "ts": 1722230000.3,
  "from": "gs",
  "data": { "cmd": "ESTOP", "target": "car" }
}
```

支持命令：`ESTOP`（急停）、`RESUME`（继续）、`ARM`/`DISARM`（无人机，调试用）。

### 2.5 `CAR_DONE` / `UAV_DONE`

```json
{ "type": "CAR_DONE", "ts": 1722230062.0, "from": "car", "data": { "lap_time": 62.0 } }
{ "type": "UAV_DONE", "ts": 1722230063.0, "from": "uav", "data": { "state": "LAND" } }
```

## 3. 通信时序

### 3.1 抛投任务时序

```
小车按键 ──UAV_START(mode=DELIVERY)──► 无人机起飞
小车循线起步 ◄──（并行）── 无人机 150cm 悬停 3s
       地面站 10Hz 转发 CAR_TELEMETRY → 无人机
       无人机 FORMATION（B 点前建立）→ DELIVERY（D 点前抛投）→ RETURN
       无人机降落 H；小车回 A 点 ──CAR_DONE──► 地面站
```

### 3.2 动态起降任务时序

```
小车按键 ──UAV_START(mode=DYNAMIC_LAND)──► 无人机起飞（15s 内小车到 B）
       无人机巡航寻找小车（经地面站转发位置）→ 飞至小车上方 → DYNAMIC_LAND
       平台停留 5s → RECHOVER 起飞 → RETURN → 降落 H
       小车回 A 点 ──CAR_DONE──► 地面站（全程 ≤90s）
```

## 4. 可靠性设计

- 关键事件消息（UAV_START/CAR_DONE）连续发送 5 次，间隔 50ms；
- 遥测消息带 `ts` 时间戳，接收端丢弃迟到 500ms 以上的旧帧；
- 地面站 1s 未收到某端遥测则标记"离线"并报警提示；
- 伴飞控制数据使用地面站转发链路，丢包率 <0.5% 时控制稳定；超过 5% 自动降级为"保持悬停等待"策略。

## 5. MAVLink 通道（无人机内部）

- 伴机电脑 ↔ 飞控：`udp://:14550`（ArduPilot SYSID=1，伴机 GCS 模式）
- 控制接口：`SET_POSITION_TARGET_LOCAL_NED`（坐标系 `MAV_FRAME_LOCAL_NED`，type_mask 使能 x/y/z/yaw）
- 状态读取：`LOCAL_POSITION_NED`、`ATTITUDE`、`BATTERY_STATUS`、`HEARTBEAT`
