# 02 · 系统架构

## 1. 总体架构

```
                        ┌───────────────────────────────┐
                        │         地面站 (PC)            │
                        │   Python 图形界面 (Tkinter)    │
                        │  · 场地实时位置图形显示          │
                        │  · 无人机状态文字显示            │
                        │  · 数据落盘 CSV                 │
                        └──────────────┬────────────────┘
                                       │ WiFi UDP (端口 14551)
                    ┌──────────────────┼──────────────────┐
                    │                  │                  │
         ┌──────────▼─────────┐  ┌────▼──────────────────────┐
         │  循线小车           │  │       多旋翼无人机          │
         │  STM32F103C8T6     │  │  Pixhawk(ArduPilot) 飞控    │
         │  · 8路灰度循线 PID   │  │  + 伴机电脑(树莓派/香橙派)    │
         │  · 编码器里程计      │◄►│  + 下视相机(视觉降落引导)    │
         │  · 轨迹地图定位      │  │  + 舵机抛投机构             │
         │  · ESP32 WiFi       │  │  + 激光测距(定高辅助)       │
         │  · 一键启动          │  │  + MAVLink over UDP       │
         └──────────┬─────────┘  └────────────▲──────────────┘
                    │                          │
                    └────── 启动指令 UAV_START ┘
                    （小车 → 无人机，UDP 直发或经地面站转发）
```

## 2. 数据流

| 消息 | 方向 | 内容 | 周期 |
|---|---|---|---|
| `UAV_START` | 小车→无人机 | 一键启动触发，无人机解锁起飞 | 事件 |
| `CAR_TELEMETRY` | 小车→地面站 | 位置(x,y)、里程s、速度v、状态 | 10Hz |
| `CAR_TELEMETRY`（转发） | 地面站→无人机 | 小车位置（伴飞跟踪输入） | 10Hz |
| `UAV_TELEMETRY` | 无人机→地面站 | 位置、高度、速度、航向、状态 | 10Hz |
| `GS_CMD` | 地面站→小车 | 可选：急停/暂停（调试用） | 事件 |
| `CAR_DONE` | 小车→地面站/无人机 | 回到 A 点任务结束 | 事件 |

## 3. 各子系统组成

### 3.1 小车（轮式循线平台）

| 部件 | 型号/规格 | 作用 |
|---|---|---|
| 主控 | STM32F103C8T6 | 循线、里程计、运动控制 |
| 循线 | 8 路灰度传感器（TCRT5000） | 识别 2cm 黑线 |
| 电机 | 2× 直流减速电机 + 13 线编码器 | 驱动 + 里程 |
| 驱动 | TB6612FNG | 电机 H 桥 |
| 通信 | ESP32-01S（UART 透传） | WiFi UDP |
| 电源 | 2S 18650 锂电 + AMS1117/MP1584 | 供电 |
| 人机 | 一键启动按键、蜂鸣器 | 启动与提示 |

小车平台 ≤60×60cm，中心绘制 50cm/30cm 同心圆 + 十字（线宽 2cm），兼顾视觉引导与载重。

### 3.2 无人机

| 部件 | 型号/规格 | 作用 |
|---|---|---|
| 机架 | 450mm 轴距四旋翼 + 全防护桨 | 平台 |
| 飞控 | Pixhawk 4（ArduPilot 4.x） | 姿态/定高/位置控制 |
| 动力 | 2212 920KV ×4 + 1045 桨 + 30A 电调 | 动力 |
| 伴机 | 树莓派 4B（或香橙派 Zero2） | 状态机/视觉/通信 |
| 相机 | CSI 800W 摄像头（向下） | 同心圆识别、降落引导 |
| 测距 | VL53L1X（I2C） | 降落阶段高度精确测量 |
| 抛投 | MG90S 舵机 + 拨杆 | 释放 25±5g 软质物 |
| 通信 | 板载/USB WiFi | MAVLink(UDP 14550) + 任务 UDP |
| 电源 | 3S 2200mAh + 5V BEC | 供电 |

### 3.3 地面站

笔记本（Windows 10/11）+ Python 3.10+。主程序 `gs_main.py`，依赖 `tkinter`、`matplotlib`（可选）、`numpy`。

## 4. 接口约定

- 坐标系：场地坐标 cm，原点为场地左下角，x 向右、y 向上；与地面站画布一致。
- 无人机本地 NED 坐标系：原点为起降点 H，x 向东（场地右）、y 向北（场地内）、z 向下；高度取 -z。
- 状态枚举：`IDLE / TAKEOFF / HOVER / FORMATION / DELIVERY / RETURN / LAND / DYNAMIC_LAND / RECHOVER / DONE / FAIL`。
