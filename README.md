# NUEDC-2026-D · 陆空协同无人机系统

2026 年全国大学生电子设计竞赛（TI 杯）赛区赛 **D 题**完整工程仓库。

> 设计并制作一款由**多旋翼飞行器、轮式循线小车和无线通信地面站**构成的陆空协同无人机系统：飞行器自主完成对小车的跟踪、物资抛投和在小车平台上的动态起降；小车作为临时起降平台循线行进一圈；地面站图形化实时显示全场信息。

---

## 一、赛题要点

| 模块 | 任务 | 分值 |
|---|---|---|
| 抛投任务 | 小车一键启动并发无线指令 → 无人机起飞悬停 → 伴飞 → 抛投 25±5g 软质物 → 返航降落 → 小车停回 A 点 | 60 |
| 动态起降 | 15s 内到 B 点，无人机巡航追车 → 小车平台动态降落 → 停留 5s → 复飞返航 | 20 |
| 地面站 | 图形化实时显示小车/无人机位置，文字显示无人机状态 | 15 |
| 其他/报告 | 设计报告 20 分 + 其他 5 分 | 25 |

- 场地 400cm×500cm，中央闭合黑色轨迹（上下 R=75cm 半圆 + 两侧 150cm 直道），周长 ≈ 771cm
- 小车单圈总时长 ≤ 90s，全程不得停车
- 无人机轴距 ≤ 45cm，桨叶全防护，巡航高度 150±10cm

## 二、系统架构

```
┌─────────────┐   UDP/JSON(WiFi)  ┌──────────────┐
│   循线小车    │◄────────────────►│   地面站 PC    │
│ STM32+编码器  │                  │ Python 图形界面 │
│ 灰度循线+里程计 │                  └──────┬───────┘
└──────┬──────┘                         │ UDP/JSON(WiFi)
       │ 启动指令(UDP)                  │
┌──────▼──────────────────────────────▼───────┐
│              多旋翼无人机                      │
│  飞控(ArduPilot) + 伴机电脑(Python) + 下视相机  │
│  状态机：起飞→悬停→伴飞→抛投→返航→降落/动态降落   │
└─────────────────────────────────────────────┘
```

- **小车**：STM32F103 主控 + 8 路灰度循线 + 编码器里程计 + ESP32 WiFi
- **无人机**：轴距 45cm 四旋翼 + Pixhawk/ArduPilot 飞控 + 伴机电脑（树莓派/香橙派）+ 下视摄像头（同心圆视觉引导降落）
- **通信**：同一 WiFi 局域网，UDP JSON 协议（见 `docs/03_通信协议.md`）

## 四、快速开始

**地面站（无需硬件即可运行仿真）**：

```bash
cd ground_station
pip install -r requirements.txt
python gs_main.py --sim          # 仿真模式，可看到小车/无人机/抛投动画
```

**小车固件**：`firmware/car/` 为 STM32CubeMX 工程源码（Cortex-M3，HAL 库），
按 `hardware/car_pinout.md` 接线后编译烧录。

**无人机端**：`firmware/uav/` 为伴机电脑 Python 程序，依赖 ArduPilot 飞控（MAVLink over UDP），
`pip install -r requirements.txt` 后按 `hardware/uav_pinout.md` 配置。

## 五、注意事项

- 本仓库为完整参考实现，具体硬件选型可按队伍现有器材替换，接口已模块化
- 遵守《中国民用航空局》相关规定，桨叶必须全防护
- 调试测试时佩戴防护眼镜、穿戴防护手套
