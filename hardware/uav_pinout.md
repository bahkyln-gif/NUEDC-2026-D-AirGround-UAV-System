# 无人机硬件接线与引脚分配（Pixhawk 4 + 树莓派伴机）

## 1. 系统组成

```
                    ┌───────────────────────────┐
                    │      树莓派 4B (伴机)      │
                    │  GPIO: 舵机/激光测距 I2C   │
                    │  USB: 摄像头 / WiFi 网卡   │
                    └──────┬──────────┬─────────┘
                           │MAVLink   │I2C(GPIO)
                     UDP:14550        │
                    ┌──────▼──────┐   │  ┌─────────────┐
                    │  Pixhawk 4   │   └──┤ VL53L1X 激光 │
                    │  ArduPilot   │      └─────────────┘
                    └──┬───┬───┬──┘
                    ESC1  ESC2 ESC3 ESC4
                    M1~M4 电机（全防护桨）
```

## 2. 飞控接线（Pixhawk 4）

| 接口 | 连接 | 说明 |
|---|---|---|
| TELEM1 | 树莓派 UART（经 USB 转 TTL 或直接 USB） | MAVLink，伴机 GCS |
| USB | 树莓派 USB（可选） | 调试 |
| PWM OUT 1~4 | 电调信号 | M1~M4 |
| 8-Pin AUX 1 | 舵机（抛投机构） | 可选：改用伴机 GPIO 控制 |
| I2C | 外接罗盘（可选） | 室内任务可不用 GPS |
| POWER | 电源模块 | 电压/电流监测 |
| GPS | M8N（可选） | 外场备用 |

## 3. 伴机电脑引脚（树莓派 40pin）

| 功能 | 引脚 | 说明 |
|---|---|---|
| 抛投舵机信号 | GPIO17 (pin 11) | PWM 输出（pigpio/软件 PWM） |
| VL53L1X SDA | GPIO2 (pin 3) | I2C1 |
| VL53L1X SCL | GPIO3 (pin 5) | I2C1 |
| VL53L1X XSHUT | GPIO27 (pin 13) | 复位控制（可选） |
| 状态 LED | GPIO22 (pin 15) | 运行指示 |
| 电源 | 5V (pin 2/4) + GND | 经 BEC 供电 |

## 4. 抛投机构

```
舵机 MG90S ── 拨杆
  拨杆托住软质物（25±5g 海绵包）置于平台边缘
  舵机旋转 90° → 拨杆放开 → 软质物自由下落
```

- 舵机供电：5V（与伴机分开的 BEC，避免干扰）
- 固定：3D 打印支架或铝合金 L 件，安装于机架中心下方

## 5. 相机安装

- CSI 摄像头朝下安装于机腹，镜头中心尽量与机架几何中心重合
- 视场角需覆盖 60×60cm 小车平台（高度 150cm 时），建议 ≥70° 视场
- 标定：拍摄已知尺寸图案，求地面分辨率 k (cm/pixel)

## 6. 电源

```
3S 电池 ──┬── 分电板 ── 4×ESC ── 电机
          └── 5V/3A BEC ── 树莓派 + 舵机（舵机建议独立 BEC）
```
